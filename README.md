# BlogSphere — Thiranex Task 4
Full-stack blog platform with JWT authentication, blog CRUD, comments, REST APIs and MongoDB.

## Run
Backend:
`cd server`
`npm install`
`copy .env.example .env`
Set MongoDB URI + JWT secret, then `npm run dev`

Frontend:
`cd client`
`npm install`
`copy .env.example .env`
Then `npm run dev`

Never commit `.env`.
